# Petits Problèmes d'Échecs ♞

Jeu de problèmes d'échecs (puzzles) en plein écran pour apprendre aux enfants.

- 4 niveaux : Très facile, Facile (mat en 1), Moyen, Difficile (mat en 2)
- Toucher ou glisser les pièces, indices, étoiles de progression (sauvegardées dans le navigateur)
- Site statique (dossier `public/`), déployé sur Vercel

Les problèmes ont été générés puis vérifiés automatiquement avec [chess.js](https://github.com/jhlywa/chess.js) (licence BSD-2).
